## 粗略深度核对

从验证图中按画面观察选取第 0、2331、3330 帧。这三帧的两侧灯条清楚，板面近似正对。用检测角点上边 `0–1` 与下边 `3–2` 的像素长度取平均得到 `p`，用水平焦距 `fx = 1781.053454 px` 和模型板宽 `W = 0.135 m` 计算 `Z_rough = fx × W / p`。相对差异按 `|Z_rough − tz| / tz × 100%` 计算，其中 `tz` 取 PnP 平移向量的第三个分量。

| 帧号 | 像素宽度 `p`（px） | 粗估深度 `Z_rough`（m） | PnP 深度 `tz`（m） | 相对差异 |
| ---: | ---: | ---: | ---: | ---: |
| 0 | 87.3716 | 2.75195 | 2.74996 | 0.07% |
| 2331 | 89.4545 | 2.68787 | 2.68913 | 0.05% |
| 3330 | 91.3503 | 2.63209 | 2.63714 | 0.19% |

三帧的粗估深度与 PnP 深度均相差不到 0.2%。粗估法假设板面近似正对且畸变影响较小。板面转向侧面时，成像宽度可能缩短，粗估深度随之增大。灯条检测给出的角点位置也会影响结果。两种方法共用检测角点与标定数据，表中的百分比只衡量两种估计之间的差异。

## 单因素敏感性实验

复用第 0、2331、3330 帧。逐帧复制检测角点，将角点 `0`（左上角）的横坐标加 `2 px`，保留其余坐标和相机、模型参数，再解算一次。原位姿作基准。两次重投影误差都相对于各自解算所用的角点计算。下表每项为「扰动前 → 扰动后（变化量）」，变化量取扰动后减扰动前，由程序在显示舍入前计算。

| 帧号 | 深度 `tz`（m） | 直线距离 `distance`（m） | 平均重投影误差（px） |
| ---: | ---: | ---: | ---: |
| 0 | 2.74996 → 2.77638（+0.0264192） | 2.79875 → 2.82562（+0.0268746） | 0.193406 → 0.209805（+0.0163993） |
| 2331 | 2.68913 → 2.71372（+0.0245902） | 2.74544 → 2.77055（+0.0251163） | 0.209110 → 0.181565（−0.0275453） |
| 3330 | 2.63714 → 2.66213（+0.0249904） | 2.65990 → 2.68513（+0.0252303） | 0.259726 → 0.189787（−0.0699389） |

三个样例的深度增大约 2.46～2.64 cm，直线距离增大约 2.51～2.69 cm。第 2331、3330 帧的重投影误差反而减小，说明扰动后的角点也可能被模型拟合得更紧。判断深度是否可靠时，需要结合角点质量和深度核对，重投影误差用于衡量拟合的一致性。

## 位姿可信度判据

以下规则用于复核本次指定视频 `outpost.avi`，整段视频采用同一组阈值。

| 判定 | 条件 | 处理方式 |
| --- | --- | --- |
| 无有效位姿 | 四角点不可用、PnP 解算失败、位姿或误差有非有限值，或 `tz ≤ 0` | 保留帧号和失败原因，位姿数值不进入可信结果统计。 |
| 可疑 | 通过上述有效性检查，但平均重投影误差 `> 0.50 px`，或 `tz` 超出 `[2.50, 3.20] m`，或回看图像时发现灯条配对、角点位置明显异常 | 保留日志并标记复核，结合原帧和四角点排查原因。 |
| 可记录 | 通过有效性检查，且未触发可疑条件 | 保留位姿和误差，用于本次实验分析。 |

**阈值依据。** 样例全片的平均重投影误差最大约为 0.290 px。取 0.50 px 作为复核线，给样例中正常波动留出余量，同时标出明显偏离当前拟合水平的结果。样例的 `tz` 约为 2.59～3.11 m，取稍宽的 2.50～3.20 m 作为本段视频的深度复核区间。这两项是根据当前样例设定的经验阈值，换视频或拍摄距离后应重新评估。

**可能误报或漏报的情况。** 倾斜、模糊或部分遮挡会使拟合误差变大，真实位姿仍可能合理。角点系统性偏移也可能得到很小的拟合误差。比如第 3330 帧扰动后，误差从 0.260 px 降到 0.190 px，`tz` 却增加了约 2.50 cm，仍会通过两项数值阈值。近似正对的帧可用 `Z_rough` 辅助核对量级，斜视帧优先回看角点与灯条的对应关系。

本节是验收复核规则。当前程序的 `pnp_valid` 仍用于表示解算是否通过现有有效性检查。
